# V3.12 — TIP Library Curriculum Migration

## Product rule

**Rich curriculum. Invisible intelligence. Simple prescription. Clear execution.**

The golfer-facing Library is intentionally simple. Internal family, focus and coaching relationships remain metadata for TIP rather than navigation the golfer has to understand.

## Source of truth

V3.12 migrates from the exact legacy application repository:

`GavinOLearyGH/TIP_OS_v2.9.8.5_PWA`

Source file:

`data/tip-curriculum-v1.js`

The curriculum embedded in that application identifies itself as:

- Curriculum version: `2.7.0`
- Release: `TIP OS v2.7.0 PWA — Deliberate Assignments`
- Total lessons: **475**

The migration is reproducible with:

`scripts/import-v2-curriculum.mjs`

The generated production payload is:

`js/coach/legacy-library-data.js`

Do not hand-edit the generated payload.

## Verified V2 carry-forward

V3.12 treats a legacy lesson as a browsable practice when the V2 source itself says:

- foundation is Swing, Skill, Stretch or Strength;
- `practiceReady === true`; and
- `libraryVisible !== false`.

The exact migration result is:

| Dimension | V2 practice-ready + visible imported |
| --- | ---: |
| Swing | 102 |
| Skill | 183 |
| Stretch | 75 |
| Strength | 80 |
| **Total** | **440** |

That is **440 / 440 eligible practices — 100% of the V2 curriculum that meets the source's own practice-ready/library-visible rules**, and **92.6% of all 475 source lessons**. The remaining 35 source lessons are retained in migration accounting but are not promoted into the golfer-facing practice catalog because V2 itself did not mark them ready and visible.

## What is preserved from V2

The production migration keeps the practice information required to make the legacy work useful rather than merely searchable:

- title;
- dimension;
- skill;
- area;
- summary / purpose;
- locations;
- equipment;
- duration and dose;
- instructions;
- success standard;
- make-it-easier guidance;
- make-it-harder guidance;
- what to notice;
- TIP coaching note;
- Journal prompt;
- safety guidance;
- legacy lesson ID.

The generated catalog also adds hidden V3 coaching metadata (`focusKeys` and conservative `familyIds`). These fields are for TIP's recommendation logic only and are never presented as golfer-facing taxonomy.

## Golfer-facing Library

**TIP Library** is reachable directly from the TIP page and remains available from the quick-practice flow.

The golfer sees only:

**All · Swing · Skill · Stretch · Strength**

plus search and the actual practices. They do not need to understand TIP9 family IDs, family graphs, focus-key relationships, source versions or migration structure.

Library rows are deliberately compact. Opening a migrated practice shows its real execution content: what is needed, what to do, success standard, coaching cue and easier/harder variants. Unique TIP7 movements appear as ordinary Stretch or Strength curriculum rather than exposing TIP7's internal program structure.

## Execution boundary in V3.12

The content catalog is unified while execution remains intentionally conservative:

- TIP9 remains a proven nine-ball execution format and recommendation layer.
- TIP7 remains the seven-minute body execution format.
- Migrated V2 practices are fully browsable with their validated practice instructions.
- Custom Build continues to use the proven TIP9/TIP7 execution adapters in V3.12.
- Hidden `focusKeys` and `familyIds` provide the seam for progressively prescribing individual migrated practices later without changing what the golfer has to learn.

This avoids presenting an internal coaching family as if it were a separate practice simply to make the architecture visible.
