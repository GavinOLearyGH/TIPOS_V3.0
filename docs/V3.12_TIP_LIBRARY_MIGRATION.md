# V3.12 — TIP Library Curriculum Migration

## Product rule

**Rich curriculum. Invisible intelligence. Simple prescription. Clear execution.**

The golfer-facing Library is intentionally simple. Internal family, focus and coaching relationships remain metadata for TIP rather than navigation the golfer has to understand.

## Source of truth

V3.12 migrates from the exact legacy application repository:

`GavinOLearyGH/TIP_OS_v2.9.8.5_PWA`

Source file:

`data/tip-curriculum-v1.js`

The curriculum embedded in that application identifies itself as:

- Curriculum version: `2.7.0`
- Release: `TIP OS v2.7.0 PWA — Deliberate Assignments`
- Total lessons: **475**

The migration is reproducible with:

`scripts/import-v2-curriculum.mjs`

The generated production payload is:

`js/coach/legacy-library-data.js`

Do not hand-edit the generated payload.

## Verified V2 carry-forward

V3.12 treats a legacy lesson as a browsable practice when the V2 source itself says:

- foundation is Swing, Skill, Stretch or Strength;
- `practiceReady === true`; and
- `libraryVisible !== false`.

The exact migration result is:

| Dimension | V2 practice-ready + visible imported |
| --- | ---: |
| Swing | 102 |
| Skill | 183 |
| Stretch | 75 |
| Strength | 80 |
| **Total** | **440** |

That is **100% of the V2 curriculum that meets the source's own practice-ready/library-visible rules**, and **92.6% of all 475 source lessons**. The remaining 35 source lessons are not promoted into the browsable practice catalog by those source rules.

## What is preserved from V2

The production migration keeps the practice information required to make the legacy work useful rather than merely searchable:

- title;
- dimension;
- skill;
- area;
- summary / purpose;
- locations;
- equipment;
- duration and dose;
- instructions;
- success standard;
- make-it-easier guidance;
- make-it-harder guidance;
- what to notice;
- TIP coaching note;
- Journal prompt;
- safety guidance;
- legacy lesson ID.

The generated catalog also adds hidden V3 coaching metadata (`focusKeys` and conservative `familyIds`) so the curriculum can progressively feed TIP's prescription logic without exposing that taxonomy in the golfer UI.

## Golfer-facing Library

The old TIP9-only `Browse all practices` screen becomes **TIP Library**.

The golfer sees only:

**All · Swing · Skill · Stretch · Strength**

and can search the complete curriculum.

Library rows are deliberately compact. Opening a legacy practice shows its actual migrated execution content: what is needed, what to do, success standard, coaching cue and easier/harder variants. Native TIP9 families retain their Level 1–3 state and can still launch the existing nine-ball execution flow.

## Execution boundary in V3.12

The catalog is now unified for browsing and internal coaching metadata, but prescription execution remains intentionally conservative:

- TIP9 families use the proven TIP9 execution engine.
- TIP7 remains the seven-minute body program.
- Migrated V2 practices are fully browsable with their validated practice instructions.
- Custom Build still uses the native TIP9/TIP7 execution adapters in V3.12; the hidden legacy family/focus mappings create the seam for safely expanding prescription across the 440 migrated practices without making the UI more complicated.

This boundary avoids claiming that a migrated practice has been converted to the V3 execution format before an execution adapter exists for it.

## Validation

V3.12 browser validation explicitly checks that:

- the unified Library contains 503 items;
- all four dimension filters are present;
- each dimension contains substantially more than the old 26-item TIP9-only Library;
- migrated V2 instructions and success standards are visible in practice detail;
- Stretch and Strength contain legacy curriculum beyond TIP7;
- native TIP9 practices still launch correctly from the unified Library.
