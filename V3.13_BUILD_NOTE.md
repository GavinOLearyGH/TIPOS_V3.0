# V3.13 — Intelligent TIP Library Search

Build scope:
- Preserve the full unified TIP curriculum.
- Keep the Library search input mounted while filtering so iOS/Safari retains keyboard focus.
- Expand search beyond title/skill/area/summary to the full practice content.
- Add a hidden golfer-language semantic signal layer so searches such as slice, hook, over the top, fat/thin, three-putt and short-sided resolve to relevant curriculum themes.
- Rank results by exact title, skill/area, semantic signal, then full-text content.

The semantic signal map is internal curriculum intelligence and is not shown to the golfer.
